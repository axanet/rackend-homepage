# Security policy

This repository is a static website. It has no server-side code, accounts or
user data. Security issues in rackend itself are covered by the
[rackend security policy](https://github.com/axanet/rackend/security/policy).

## Reporting a vulnerability

If you find a security problem with the site or its container image (for
example a vulnerable dependency, an unsafe header or a supply chain issue),
please report it privately through
[GitHub's private vulnerability reporting](https://github.com/axanet/rackend-homepage/security/advisories/new).
Do not open a public issue.

We aim to acknowledge reports within a few working days.
